## What it is

A tiny Python program that writes one short piece of text — eight lines
about the tide coming in after dark and a small light left burning in an
unwatched window. The image is deliberately quiet: nothing hurries, nothing
asks, and the sea simply keeps its slow promise to return. The aim is a
feeling of awe that arrives softly, through patience and repetition, rather
than through spectacle.

## How to run

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

That writes the entry text to `out/entry.txt`. The program uses only the
Python 3.13 standard library and makes no network calls.
